# Registro de Avances (Roadmap)

## Fase 1: Datos y Estructura Base
- [ ] Crear proyecto en Godot.
- [ ] Crear el script `SkeletonData.gd` (Resource).
- [ ] Crear 3 Resources de prueba (Tier 1, Tier 2, Tier 3).
- [ ] Crear e inicializar el Autoload `GameManager.gd`.

## Fase 2: Catacumba y Fusión
- [ ] Configurar la interfaz (UI) de la catacumba con un `GridContainer`.
- [ ] Programar la lógica de creación (compra) de esqueletos de Tier 1.
- [ ] Implementar Drag & Drop nativo de Godot para mover esqueletos.
- [ ] Implementar lógica de fusión (Merge) al soltar un esqueleto sobre otro idéntico.

## Fase 3: Economía y Tiempo
- [ ] Programar la función del botón "Avanzar Día".
- [ ] Calcular y sumar las Almas generadas por todos los esqueletos en el tablero.
- [ ] Bloquear la interfaz de preparación al llegar al Día 5.

## Fase 4: Combate
- [ ] Crear la interfaz `CombatScreen.tscn`.
- [ ] Programar la carga del equipo desde `GameManager` a la escena de combate.
- [ ] Programar la máquina de estados de los turnos.
- [ ] Lógica de victoria (reiniciar día a 1, dar almas) y derrota (Game Over).
